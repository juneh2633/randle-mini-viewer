# Android 앱

Android 8.0 이상에서 실행하는 랜들 미니 뷰어의 시험 버전입니다. 화면 속 화면(PiP) 기능이 있는 기기가 필요하며 갤럭시 S23 울트라를 사용 대상으로 개발했습니다.

## 사용

1. APK를 설치하고 앱 안에서 랜들에 로그인합니다. Chrome과 로그인 상태를 공유하지 않습니다.
2. 웹 페이지나 화면 아래 수동 버튼으로 숫자를 뽑고, 리롤할 자리를 선택하거나 확정합니다.
3. 오른쪽 위 **PiP**를 누르면 작은 창으로 전환됩니다. 다른 앱을 열어도 숫자와 남은 시간을 볼 수 있습니다.
4. PiP 창을 한 번 누르면 시스템 메뉴에 **확정**, **숫자 뽑기 / 다음 판** 버튼이 나타납니다. 현재 게임에서 가능한 버튼만 활성화됩니다.
5. 자리 선택·리롤·인증은 PiP 창을 펼쳐 원래 앱 화면에서 직접 진행합니다. 인증이 필요하면 작은 창에 표시됩니다.

사용자가 누른 동작만 한 번 전달하며 자동 반복 기능은 없습니다. 사이트 자체의 자동 확정 시간은 계속 흐릅니다. 스마트폰에서 홈으로 나가거나 앱을 닫았다고 해서 게임의 제한 시간이 멈추지는 않습니다. PiP를 사용하려면 앱의 PiP 버튼을 누르세요.

앱을 처음 실행할 때 PiP가 열리지 않으면 갤럭시 설정에서 이 앱의 **화면 속 화면** 허용 여부를 확인하세요. 앱을 완전히 종료하거나 기기 절전 정책으로 중단하면 숫자 갱신도 중단됩니다. 기기마다 PiP 메뉴와 화면 크기는 다를 수 있습니다.

## 시험 APK

현재 APK는 개발용 서명으로 빌드됩니다. 이전 시험 APK와 서명이 달라 업데이트가 안 되면 이전 앱을 지우고 다시 설치해야 하며, 이때 앱 안의 로그인 정보도 삭제됩니다. 정식 Play 스토어 배포본이 아닙니다.

실제 S23 울트라에서의 로그인, 인증, 다른 앱과의 PiP 동작은 기기 확인이 필요합니다. 특히 일부 외부 로그인 제공자는 앱 안의 브라우저 로그인을 제한할 수 있습니다. 앱은 보안 경고나 로그인 제한을 우회하지 않습니다.

## 데이터와 권한

인터넷 권한만 사용합니다. 로그인을 유지하기 위한 웹 쿠키와 사이트 저장소는 Android WebView 내부에 저장됩니다. 앱이 비밀번호를 따로 수집하거나 개발자 서버로 보내지 않으며, 외부 앱의 화면을 읽거나 다른 앱 위에 그리기 권한을 요청하지 않습니다. 게임 조작 코드는 랜들의 HTTPS `/play` 페이지에서만 실행됩니다.

## 빌드

JDK 17, Gradle 8.11.1, Android SDK 35가 필요합니다.

```sh
gradle -p android :app:assembleDebug :app:lintDebug
```

APK는 `android/app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 숫자 추출과 수동 조작에는 PC 버전의 `extension/viewer.js`를 빌드 시 복사하여 사용합니다. 자동화용 코드는 포함하지 않습니다. GitHub Actions의 **Android APK** 워크플로에서도 빌드할 수 있습니다.
