# Android 앱

Android 8.0 이상에서 실행하는 랜들 미니 뷰어의 시험 버전입니다. 화면 속 화면(PiP) 기능이 있는 기기가 필요하며 갤럭시 S23 울트라를 사용 대상으로 개발했습니다.

## 사용

1. APK를 설치하고 앱 안에서 랜들에 로그인합니다. Chrome과 로그인 상태를 공유하지 않습니다.
2. 화면 위쪽 **작은 창**을 누릅니다. 처음에는 Android 설정에서 이 앱의 **다른 앱 위에 표시** 권한을 직접 허용하고 돌아옵니다.
3. 다른 앱 위에 게임 창이 표시됩니다. 숫자 자리를 직접 선택하고 **전체 선택 / 선택 자리 굴리기 / 이 숫자로 확정 / 다음 판**을 누를 수 있습니다.
4. 창 상단 **⠿ 랜들** 부분을 끌어 위치를 바꿉니다. 오른쪽 아래 **크기 조절 ↘**을 끌거나 **크게 / 작게**를 눌러 크기를 조절합니다.
5. 기본 창은 약 **260 × 220dp**로 숫자와 작은 조작 버튼을 표시합니다. **크게**를 누르면 웹 화면도 펼쳐져 직접 터치·스크롤·키보드 입력을 할 수 있습니다. 로그인이나 인증을 마친 뒤 **작게**로 돌아오세요. 창을 줄이면 키보드도 닫힙니다.
6. **앱**을 누르면 현재 페이지를 그대로 전체 앱으로 옮깁니다. **닫기**를 누르면 작은 창과 실행 서비스가 종료됩니다. 진행 중인 페이지를 새로 열지 않으므로 전환할 때 선택한 자리와 입력 중인 내용이 유지됩니다.

**PiP** 버튼도 계속 제공합니다. PiP는 숫자 표시 및 시스템 메뉴의 확정·다음 판만 지원합니다. 창 안에서 모든 수동 버튼을 누르려면 **작은 창**을 사용하세요.

기본은 수동 모드입니다. 사이트 자체의 자동 확정 시간은 계속 흐릅니다. 스마트폰에서 홈으로 나가거나 앱을 닫았다고 해서 게임의 제한 시간이 멈추지는 않습니다. PiP를 사용하려면 앱의 PiP 버튼을 누르세요.

## 자동 실행 명령

전체 앱에서는 상단 앱 제목을, 작은 창에서는 숫자 위 상태 문구를 길게 누르면 명령 입력창이 열립니다.

- `/auto start`: 자동 뽑기와 확정을 시작합니다. 숫자 8자리가 모두 공개되면 **1초 후** 확정하고 다음 판을 시작합니다.
- `/auto pause`: 일시 정지합니다. 활성화 후 표시되는 **자동 일시 정지** 버튼도 사용할 수 있습니다.
- `/auto resume`: 일시 정지한 자동 실행을 재개합니다. 확인 대기 시간도 다시 시작합니다.
- `/auto stop`: 자동 모드를 끄고 수동 모드로 돌아갑니다.

자리 선택이나 리롤 등 직접 조작을 하면 자동 실행이 일시 정지됩니다. 리롤은 직접 눌러야 합니다. 인증을 감지하면 멈추며, 직접 인증을 마친 뒤 재개해야 합니다. 작은 창의 **크게**로 인증 화면을 펼칠 수 있습니다. 화면이 꺼지거나, 작은 창·PiP 없이 앱이 가려지거나, 페이지를 벗어나거나, 3분간 진행이 없을 때도 정지합니다.

앱과 작은 창 사이 전환에서는 실행 상태가 유지되지만 새로고침·페이지 재로딩·앱 재실행 후에는 수동 모드입니다. 상태 확인은 0.5초 간격이므로 실제 확정 시점은 약간 늦어질 수 있습니다. 사이트 버튼이 비활성화된 동안은 기다립니다. 명령은 공개 소스에 포함된 기능 전환용으로 비밀번호나 접근 제한 수단이 아닙니다.

PiP가 열리지 않으면 갤럭시 설정에서 이 앱의 **화면 속 화면** 허용 여부를 확인하세요. **작은 창**은 별도의 **다른 앱 위에 표시** 권한을 사용합니다. 창 실행 중에는 Android의 실행 상태 표시용 알림이 유지되며 알림의 닫기로도 종료할 수 있습니다. 최근 앱에서 앱을 제거하거나 기기 절전 정책으로 중단하면 창과 숫자 갱신도 종료됩니다.

## 시험 APK

[Android 0.3.0 릴리스](https://github.com/juneh2633/randle-mini-viewer/releases/tag/android-v0.3.0)에서 APK를 받을 수 있습니다.

현재 APK는 개발용 서명으로 빌드됩니다. 이전 시험 APK와 서명이 달라 업데이트가 안 되면 이전 앱을 지우고 다시 설치해야 하며, 이때 앱 안의 로그인 정보도 삭제됩니다. 정식 Play 스토어 배포본이 아닙니다.

실제 S23 울트라에서의 로그인, 인증, 다른 앱과의 PiP 동작은 기기 확인이 필요합니다. 특히 일부 외부 로그인 제공자는 앱 안의 브라우저 로그인을 제한할 수 있습니다. 앱은 보안 경고나 로그인 제한을 우회하지 않습니다.

## 데이터와 권한

인터넷, **다른 앱 위에 표시**, 작은 창을 유지하기 위한 포그라운드 서비스 권한을 사용합니다. 표시 권한은 작은 창을 처음 열 때 사용자가 직접 허용합니다. 서비스를 자동 시작하거나 자동 재실행하지 않습니다. 로그인을 유지하기 위한 웹 쿠키와 사이트 저장소는 Android WebView 내부에 저장됩니다. 앱이 비밀번호를 따로 수집하거나 개발자 서버로 보내지 않으며, 외부 앱의 화면을 읽거나 촬영하지 않습니다. 게임 조작 코드는 랜들의 HTTPS `/play` 페이지에서만 실행됩니다.

## 빌드

JDK 17, Gradle 8.11.1, Android SDK 35가 필요합니다.

```sh
gradle -p android :app:assembleDebug :app:lintDebug
```

APK는 `android/app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 숫자 추출과 수동 조작에는 PC 버전의 `extension/viewer.js`를 빌드 시 복사하여 사용합니다. 명령으로 켜는 자동 실행은 Android 전용 `auto.js`에 있으며 PC 확장 프로그램에는 포함되지 않습니다. GitHub Actions의 **Android APK** 워크플로에서도 빌드할 수 있습니다.
