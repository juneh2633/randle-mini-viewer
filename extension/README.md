# 랜들 미니 뷰어 v1.0.0

유튜브 등 다른 탭을 보면서 랜들의 현재 숫자를 확인하는 보기 전용 확장 프로그램입니다.

## 설치

1. 받은 ZIP 파일을 새 폴더에 압축 해제합니다.
2. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`를 엽니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드**를 선택합니다.
4. 압축 해제한 폴더 안에서 `manifest.json`이 있는 폴더를 선택합니다.
5. https://randle.lixx.kr/play 를 열거나 새로고침합니다.
6. 오른쪽 아래 **항상 위 미니 창 ↗**을 누른 뒤 원하는 탭으로 이동합니다.

## 사용

- 숫자는 공개된 자리부터 즉시 표시되고, 미공개 자리는 `?`로 나옵니다. 앞자리 0도 그대로 표시합니다.
- 미니 창은 마우스로 위치와 크기를 바꿀 수 있습니다.
- 사이트에 표시되는 자동 확정 시간이 있다면 함께 보여 줍니다.
- 인증이 필요하면 미니 창에 안내가 표시됩니다. 창 제목 표시줄의 **탭으로 돌아가기**를 사용해 랜들에서 직접 인증하세요.
- 게임 시작·리롤·확정은 원래 랜들 탭에서 직접 조작합니다.
- 원래 랜들 탭은 열어 두세요. 새로고침하거나 닫으면 미니 창도 닫히므로 다시 열어야 합니다.
- 지원 대상은 Document Picture-in-Picture 기능이 있는 데스크톱 Chrome / Edge입니다. 모바일, 전체 화면, 브라우저 관리 정책에 따라 표시가 제한될 수 있습니다.

## 개인정보

랜들 `/play` 페이지에서 숫자와 게임 상태를 읽어 표시합니다. 게임 버튼을 자동으로 누르지 않으며, 계정 정보나 숫자를 저장하거나 외부 서버에 보내지 않습니다.

이 ZIP은 수동 설치용 배포 파일입니다. Chrome 웹 스토어 / Edge 추가 기능 스토어에 등록된 파일은 아닙니다.
